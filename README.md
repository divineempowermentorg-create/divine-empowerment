Divine Empowerment — Quick Launch Guide

HOW TO PUBLISH (GitHub Pages)
1) In the repo, click “Add file” → “Create new file”
2) Name it: index.html → paste the site file → Commit changes
3) Settings → Pages → Source: Deploy from a branch; Branch: main; Folder: /(root) → Save
4) Open: https://divineempowermentorg-create.github.io/divine-empowerment/
