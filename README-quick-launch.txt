Divine Empowerment — Quick Launch Guide
- index.html  (your entire website in one file)

FASTEST WAYS TO PUT IT ONLINE
1) Netlify Drop: https://app.netlify.com/drop  → drag index.html → live URL
2) Vercel: https://vercel.com  → New Project → drag index.html or import from GitHub
3) GitHub Pages: upload index.html → Settings → Pages → Deploy from main → /(root)

DONATION LINK
Open index.html and add your PayPal/GiveButter link where you want it.
