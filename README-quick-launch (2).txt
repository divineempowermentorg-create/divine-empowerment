Divine Empowerment — Quick Launch Guide

FILES INCLUDED
- index.html (your entire website in one file)

HOW TO PUT IT ONLINE
1. Netlify Drop (Easiest)
   - Go to https://app.netlify.com/drop
   - Drag and drop index.html into the page.
   - You’ll get a live link instantly.

2. Vercel
   - Go to https://vercel.com
   - Create a new project and upload index.html.
   - It will automatically deploy and give you a link.

3. GitHub Pages
   - Create a new repository on GitHub.
   - Upload index.html to the repo.
   - Go to Settings → Pages → select "Deploy from a branch" → /(root).

ADDING YOUR BRAND ASSETS
- Create an /assets folder and upload your images:
  logo-header-192.png
  logo-512.png
  favicon.png
  social-card.png
  logo-transparent.png

CUSTOM DOMAIN & EMAIL
- You can connect divineempowerment.org through your hosting provider.
- Set up info@divineempowerment.org via Google Workspace or Zoho Mail.
